# 🏨 Hotel Business Database Project

## 📜 Description

This project demonstrates database modeling for a hotel business. It includes the creation of tables, views, triggers, sequences, and various SQL queries with comments and examples. The goal is to show practical usage of SQL in managing hotel data.

## 📁 Project Structure

- `Assigment1.sql` — the main SQL file with:
  - Table creation (hotel, service, guest, room, reservation, guest_service, staff)
  - Views using joins, aggregations, set operations, and nested selects
  - Triggers and sequences for automating primary key generation and data validation

- `samplee.pdf` — documentation (in Slovak) describing the purpose and behavior of the queries and SQL logic implemented.

## 🚀 Features

- ✅ Complex views over single and multiple tables
- ✅ Aggregated statistics (e.g., average room/service prices)
- ✅ Nested queries and set operations
- ✅ Triggers for automatic key generation and availability checks
- ✅ Focus on hotel reservations, services, and room/guest management

## 🛠️ Requirements

Any SQL-compatible RDBMS (preferably Oracle or PostgreSQL due to triggers/sequences usage).

## 📚 Usage

1. Run the SQL script `Assigment1.sql` in your database environment.
2. Verify tables, insert sample data, and test the views and triggers.
3. Use the `samplee.pdf` file for understanding the logic behind each component.
